# SMK-37 Looper — гитарный лупер с MIDI-контроллером

Программа превращает MIDI-клавиатуру **M-VAVE SMK-37 Pro** (или любую другую)
в пульт управления гитарным лупером:

1. Гитару подключаете к аудиовходу компьютера (встроенная звуковая карта или внешний интерфейс).
2. Нажимаете кнопку **Запись** → играете фразу; все лупы при этом играют в одном тайминге.
3. Нажимаете кнопку ещё раз → запись заканчивается, цикл бесшовно крутится дальше.
4. Поверх цикла можно писать **дубль** (overdub), отменять его (**Undo**),
   переключаться между **4 слотами** лупов — все слоты играют одновременно.

## Возможности

- **MIDI-инструмент** (вкладка «MIDI»): клавиатура SMK-37 (или любая другая)
  играет звуки прямо в программе — 17 инструментов (пианино, органы, гитары,
  басы, струнные, хор, духовые, синты) + ударные GM-кит. Инструмент звучит
  всегда и **пишется в луп вместе с гитарой** — как живая игра. Есть педаль
  сустейна (CC64), демо-фраза, громкость. Ноты с назначенными действиями
  остаются кнопками управления.
- **Единый тайминг на все лупы** (как в аппаратных луперах): одна «полоска»
  позиции, все лупы одной длины, играют с одной и той же позиции — в разнобой
  не расходятся. Длина цикла = такты × блоки (например 4 × 2 = 8 тактов).
- **Один общий темп** (BPM + размер — в блоке «Запись: темп, такты и блоки»):
  темп управляет и метрономом, и длительностью тактов. Размер — это долей
  в такте (4/4 = 4 доли в такте; акцент метронома — на первой доле такта).
  Меньше BPM — такты ДЛИННЕЕ по времени (цикл длиннее), больше BPM — короче.
  Уже записанный материал пересчитывается вместе с темпом (как на ленте) —
  метроном, сетка и запись всегда в одном темпе.
- **«Запись/Дубль»** запускает проигрывание всех лупов и пишет только выбранный
  (кнопка лупа становится красной); повторное нажатие останавливает запись
  (кнопка снова зелёная) — воспроизведение всех дорожек продолжается.
- **Запись — замена блоками**: пока в блоке нет порога — старый блок ИГРАЕТ;
  как только порог превышен — старая запись блока сразу удаляется и пишется
  новая (весь блок, включая начало до порога, до конца блока). Без порога блок
  не трогается — даже на следующем круге (каждый проход — свежий шанс, старое
  не перезаписывается без звука). «Вручную» — пишутся все блоки без учёта
  порога (всё зелёное).
- **«Старт/Стоп»** — пауза/продолжить все дорожки разом (позиция остаётся).
  Из полного стопа — старт сразу, с начала цикла.
- **«Стоп»** — всё останавливается, позиции сбрасываются на начало цикла,
  запись выключается до следующей команды (ничего не стартует само).
- **Undo** — отменить последнюю запись (возврат прошлого материала).
- **Красная полоска порога** на индикаторе «Вход» — двигается вместе с
  регулятором порога (удобно подбирать громкость).
- **Метроном** (щелчки: акцент — первая доля такта, остальные слабые) —
  звучит ТОЛЬКО во время проигрывания блоков (с записью или без), в цикл не
  пишется. Каждый новый запуск — с первой доли (акцент). Выключение — щелчки
  исчезают сразу; включение на лету — со следующего такта («Размер 4/4» = 4 доли).
- **Драм-машина** (кнопка рядом с метрономом) — **54 стиля: 3 варианта на каждый
  из 18 жанров** (Поп, Рок, Баллада, Фанк, Хип-хоп, Вальс, Диско, Электро, Панк,
  Гранж, Хардкор, Метал, Фолк, Сальса, Боса-нова, Регги, Хаус, Блюз). У каждого
  жанра три разных рисунка (например, «Поп 1/2/3»). Адаптация — как в
  авто-аккомпанементе Yamaha: для каждого размера свой вариант паттерна (НЕ
  сжатие 4/4!), бочка — сильная доля, малый барабан — контрдоля, хэт — ровные
  8-е/16-е. В лёгких и латино-стилях используются рим-клик и «призраки» малого.
  Темп общий с циклом; крэш — на первом такте цикла, брейк — на последнем.
  Звучит только с транспортом, в лупы не пишется; включение на лету — со
  следующего такта. В спойлере — выбор стиля, предпрослушивание (один цикл, без
  транспорта) и громкость. Одновременные удары (бочка+хэт+рабочий) звучат
  ВМЕСТЕ; звуки синтезируются без щелчков, наложение защищено мягким лимитером.
- **4 слота** лупов (большие кнопки «Луп 1…4» вплотную к волновым формам:
  активный — зелёный, записываемый — красный, приглушённый — жёлтый, остальные
  серые). Клик по кнопке — выбор слота; повторный клик по выбранному — вкл/выкл
  mute (запись не удаляется, только глушится). Переключение — с клавиатуры или мыши.
- Программный мониторинг гитары (регуляторы «Мониторинг» и «Громкость лупов»).
- Выбор любой звуковой карты для входа и выхода (встроенная или внешняя — переключаются на лету).
- **MIDI-learn**: любую кнопку/пад/клавишу/CC контроллера можно назначить на любое действие.
- Экспорт слота в WAV.

## Интерфейс

- **«Лупы»** — индикация «Вход»/«Выход» (с полоской порога), метроном,
  **общий темп** (BPM + размер 2/4…6/4), такты/блоки, режим записи
  («Вручную» / «Авто по звуку»),
  **строки лупов** (4 шт.) с кнопкой «Луп N», волноформой, сеткой тактов и
  блоков, масштаб 50–400% с прокруткой, общей позицией тайминга и транспортом.
- **«Настройки»** — устройства, буфер/частота, MIDI-назначения, журнал.

### Строки лупов

- Кнопка **«Луп N» в строке** — выбор лупа (цель для записи); **повторный клик
  по выбранной кнопке** — вкл/выкл звук этого лупа (mute). Клик по волне — только выбор.
  Цвета кнопки: серый — не выбран; **зелёный** — выбран; **красный** — идёт запись
  или ожидание звука; **жёлтый** — луп заглушён (запись цела, просто не слышно).
  При переключении во время записи прошлая кнопка гаснет в серый, новая — красная.
- В строке видно: волноформу, сетку тактов и блоков, позицию тайминга
  (жёлтая линия — одна на все лупы), состояние и длину. **Такты разделены цветом**
  (каждый следующий — чередованием светлее/темнее), **границы блоков** — заметными
  полосками, границы тактов — тонкими линиями.
- **Волноформа**: блоки закрашиваются целиком — зелёно-бирюзовый (звук прошёл порог
  или записан вручную) / серый (порога не было, блок не записан). Обновляется
  вживую во время записи.
- **Ширина дорожки подстраивается под окно**: все блоки цикла всегда вмещаются
  целиком — без зума и без полос прокрутки (окно растянул — волна растянулась).
- **Переключение лупа во время записи**: недописанный блок сохраняется
  (если был порог), текущий луп продолжает играть, а выбранный пишет
  **с текущей позиции общего тайминга** — без разнобоя.

Горячие клавиши (работают из любой вкладки): `R` — запись/дубль, `Space` — старт/стоп,
`U` — undo, `C` — очистить, `S` — стоп, `M` — метроном, `[` `]` — лупы, `1–4` — выбор лупа.

## MIDI-инструмент

Вкладка **«MIDI»** — звуки для клавиатуры.

- **Режим клавиатуры**: «Играть инструмент» (ноты звучат) или «Только управление».
  Ноты, на которые назначено действие в «MIDI-назначениях», всегда работают
  как управление — инструмент их не задевает.
- **Инструмент**: категория → список → «▶ Демо» играет короткую фразу выбранным
  звуком. Ползунок «Громкость инструмента» — общая громкость звуков.
- **Ударные (GM-кит)** — каждая клавиша = свой барабан (бочка, малый, хэты,
  томы, крэш, райд, хлопки, ковбелл).
- **Педаль сустейна** (CC64): ноты держатся, пока педаль нажата.
- Инструмент **пишется в луп вместе с входом гитары** (как ещё одна живая
  партия), но метроном и драм-машина в запись не идут — как и раньше.
- Звуки лежат в папке `sounds/` (запечены из библиотеки GeneralUser GS).
  Если папки нет — программа работает, но клавиатура молчит.

## Установка (Windows 11)

1. Установите **Python 3.11+** с [python.org](https://www.python.org/downloads/) —
   при установке обязательно поставьте галочку **«Add python.exe to PATH»**.
2. Скопируйте папку проекта к себе (например, `C:\smk37-looper`).
3. Запустите **`install.bat`** (один раз — поставит 4 пакета: numpy, sounddevice, mido, python-rtmidi).
   Если в конце написано `Successfully installed ...` — всё в порядке, просто закройте окно.
4. Запускайте **`start.bat`**.

## Первый запуск

1. В верхней панели выберите:
   - **MIDI** — `SMK-37 Pro` (если в списке два порта с похожим именем — попробуйте оба;
     рабочий определите по реакции на нажатия),
   - **Аудио вход** — ваша звуковая карта, куда включена гитара,
   - **Аудио выход** — куда идут наушники/колонки.
2. Нажмите **«Применить»**. В статусе справа должно появиться «● Слот 1: Пусто».
3. Нажмите **«Запись / Дубль»** мышкой, поиграйте, нажмите ещё раз — должен пошёл цикл
   (это проверка звука без MIDI).

## Настройка кнопок SMK-37 Pro (MIDI-learn)

1. Напротив нужного действия нажмите **«Назначить»** (например, «Запись / Дубль»).
2. В течение 15 секунд нажмите любую кнопку/пад/клавишу на SMK-37 Pro — она запомнится.
3. Повторите для остальных действий.

Рекомендуемая раскладка (на ваш вкус):

| Кнопка на SMK-37 | Действие |
|---|---|
| Пад 1 | Запись / Дубль |
| Пад 2 | Старт / Стоп |
| Пад 3 | Undo |
| Пад 4 | Очистить слот |
| Пады 5–8 / клавиши | Выбор слота 1–4 |
| Любая свободная | Стоп (всё + сброс) |

Назначения сохраняются в `looper_config.json` и переживают перезапуск.

### Как это играется (как педаль-лупер)

- **1 нажатие** «Запись/Дубль» → запускаются все лупы (общий тайминг) и идёт
  запись выбранного лупа (его кнопка — красная).
- **2 нажатие** → конец записи (кнопка снова зелёная), воспроизведение всех
  дорожек продолжается, цикл бесшовно крутится дальше.
- Запись всегда **заменяет блоки**: в «Авто по звуку» старый блок играет до
  порога, при пороге — удаляется и пишется новый; без порога блок не трогается.
  В «Вручную» — пишутся все блоки подряд.
- **Undo** — отменить последнюю запись (вернуть старый материал). **Очистить** —
  стереть слот полностью.
- **«Старт/Стоп»** — пауза/продолжить все лупы вместе. **«Стоп»** — всё стоп,
  позиции на начало.

Режим «Авто по звуку» (вкладка «Лупы»):

1. Включите метроном, задайте BPM и размер (например 120, 4/4).
2. Задайте «Тактов в блоке» и «Блоков» (длина цикла = такты × блоки).
3. Выберите «Авто по звуку», настройте порог по красной полоске на «Входе».
4. **«Запись» в «Авто по звуку» всегда встаёт в ожидание** («Ждём звук» — красная
   кнопка лупа, строка в журнале): проигрывание и запись включаются/пишут
   только С МОМЕНТА превышения порога. Если Play уже запущен — запись тоже
   не пишет ничего до первого порога (старый блок играет как обычно).
5. Блок пишется ЦЕЛИКОМ (включая начало и конец), если порог где-то в нём
   превышен — и рисуется зелёным. Блок без порога — серый и в луп не пишется
   (остаётся прошлый материал) — правило действует и на следующих кругах:
   без порога старое никогда не перезаписывается. Если молчать весь цикл —
   слот останется пустым / прошлая запись не тронется.
6. Переключение лупа при записи — новый луп пишет с текущей позиции тайминга.

Нюансы: Undo работает один раз назад (последний дубль). Все лупы всегда одной
длины и одной позиции — разнобой невозможен.

## Регуляторы

- **Мониторинг** — насколько громко слышно саму гитару через ПК (0 — не слышно).
  Если слышите гитару напрямую (direct monitor интерфейса) — поставьте 0.
- **Громкость лупов** — громкость воспроизведения циклов.
- **Буфер** — чем меньше, тем ниже задержка (64–128 для минимума; 256 — устойчивый
  рабочий вариант). Если появляются щелчки/разрывы — увеличьте.
- **Экскл. WASAPI** — забирает устройство у Windows-микшера и заметно снижает
  задержку (устройство будет занято программой на время работы).
- **Частота** — 48000 по умолчанию; меняйте только если устройство не поддерживает.

## Про задержку (латентность) и ASIO4ALL

Задержка мониторинга = драйвер устройства + буфер. Порядок приоритета режимов:

1. **ASIO** (в т.ч. ASIO4ALL) — минимальная задержка (~3–8 мс).
2. **Эксклюзивный WASAPI** — сопоставимо (~5–10 мс).
3. Обычный WASAPI — средняя.
4. MME / DirectSound — большая (30–60 мс), избегайте их.

**ASIO4ALL.** Программа уже включает поддержку ASIO автоматически (sounddevice ≥ 0.5.1).
После установки ASIO4ALL в списках появится устройство `ASIO: ASIO4ALL v2` —
выберите его **и входом, и выходом** и нажмите «Применить». Если звука нет:
откройте панель ASIO4ALL (иконка в трее) и включите там вашу звуковую карту.
Если нужно сложить вход одной карты и выход другой — включите обе в панели ASIO4ALL.

**Совет:** гитару лучше подключать к той же карте, откуда идёт звук в наушники —
это даёт дуплекс без рассинхрона и меньший буфер.

## Сохранение результата

Кнопка **«Экспорт WAV»** сохраняет текущий слот в папку `exports\` (моно WAV, 16 бит).

## Если что-то не работает

| Симптом | Что делать |
|---|---|
| «Неизвестное устройство» при подключении SMK-37 | Почти наверняка кабель без данных (charge-only). Смените кабель на data-кабель, включите задний USB 2.0. Драйвер не нужен — клавиатура class-compliant. |
| «Illegal combination of I/O devices» (-9993) при выборе внешней звуковой карты | Вход и выход работают в разных режимах host API (например, MME + WASAPI) — это нормально. Программа сама переключится в режим раздельных потоков (это будет видно в журнале). Если не помогло — выберите вход и выход с одинаковым API в скобках (например, оба WASAPI) или оба через одну карту. |
| Большая задержка между струной и звуком | См. раздел «Про задержку»: выберите ASIO4ALL или WASAPI-версии устройств, буфер 64–128, включите «Экскл. WASAPI». |
| ASIO4ALL выбран, но звука нет | Откройте панель ASIO4ALL в трее и включите там вашу звуковую карту (галочкой). |
| MIDI-кнопки не нажимаются | Убедитесь, что выбран нужный MIDI-порт (на SMK-37 их может быть 2). Проверьте, что действие назначено в списке «MIDI-назначения». |
| Щелчки, разрывы звука | Увеличьте буфер (512), отключите другие тяжёлые программы, не используйте USB-хабы. |
| Гитару не слышно | Проверьте, что выбран правильный «Аудио вход», подтяните «Мониторинг», посмотрите индикатор «Вход» (должен шевелиться при игре). |
| Высокая задержка | Уменьшите буфер (128–256). На встроенной звуковой карте Windows задержка выше, чем на внешнем интерфейсе. |
| Устройство ASIO-only не видно | Программа использует WASAPI/MME Windows. Установите [ASIO4ALL](https://asio4all.org/) — интерфейс появится в списке. |

## Структура проекта

```
looper.py        — точка входа
gui.py           — интерфейс (вкладки «Лупы» / «MIDI» / «Настройки»)
audio_engine.py  — запись/циклы/дубль/undo, такты, метроном, авто-старт
sampler.py       — MIDI-инструмент (звуки из sounds/)
midi_handler.py  — приём MIDI и MIDI-learn
config.py        — настройки (looper_config.json)
test_engine.py   — тесты логики (python test_engine.py)
test_sampler.py  — тесты сэмплера (python test_sampler.py)
sounds/          — звуковая библиотека (84 wav + manifest.json)
tools/           — bake_sounds.py (перезапекание звуков, только для разработки)
install.bat      — установка зависимостей (сам ищет Python: py -3 / python / python3)
start.bat        — запуск
```

## История версий

- **r8.8** — большая библиотека драм-стилей: 54 стиля (3 варианта каждого
  жанра) и новые жанры — панк, гранж, хардкор, металл, фолк, сальса,
